**תפקיד:** שכבת-הביצוע הריבונית של האחוזה. המכשיר של הבעלים = המנוע. GitHub = ספר-פנקס בלבד (לדגר/להציג), לא מחשב.

## למה זה קיים (ההוראה, במילים של הבעלים)
"למה בנינו הכל על ריצות גיטהאב ולא על הרשת שלנו? לא רוצה להיות תלוי בדקות שלהם. יש לי מכשיר משלי שצריך להקים על הרשת כדי להריץ את הדברים אוטונומית ריבונית."

## הארכיטקטורה — 3 שכבות, 1 אמת

```
┌────────────────────────────────────────────────────────────┐
│  המכשיר הריבוני (הבעלים)                                   │
│  ├─ Forge (port 3100) — מנוע-ביצוע + מתזמן-cron מובנה      │
│  │    · lanes/ — מסילות-האחוזה רצות כאן. אפס דקות-GitHub.  │
│  │    · קבלות-ריצה (receipts) חתומות-SHA-256               │
│  ├─ anchor/ — טביעת-אצבע של כל-ריצה → מוכנה לפרסום-שרשרת  │
│  │    (החתימה מבוצעת רק בכספת הבעלים, על המכשיר שלו)       │
│  └─ register-gh-runner.sh (רשות) — המכשיר כ-runner רשמי     │
│       של GitHub → ריצות-workflow על החומרה שלנו, 0 דקות    │
├────────────────────────────────────────────────────────────┤
│  GitHub = ספר. מקבל קבלות/תוצאות ב-push. לא מריץ כלום קריטי│
├────────────────────────────────────────────────────────────┤
│  השרשרת שלנו = עוגן. קבלת-ריצה (hash) עולה לשרשרת דרך     │
│  הכספת — פנקס שאי-אפשר למחוק בלי שייראו.                  │
└────────────────────────────────────────────────────────────┘
```

## הרמה על המכשיר שלך (הבעלים) — פקודה אחת

```bash
bash setup-device.sh
```

מה זה עושה (מדוד, צעד-צעד, כנה בכל-כשל):
1. בודק תלויות (bun/git/curl) — מציג מה חסר
2. מקים את Forge (clone קיים או תיקיית-Forge שסיפקת) + db + port 3100
3. מתקין unit-systemd → עולה ב-boot, קם אחרי קריסה (Restart=always)
4. רושם את מסילות-האחוזה כ-cron-triggers בתוך Forge (אין cron-חיצוני — Forge הוא המתזמן)
5. בודק: health + ריצת-ביקורת ראשונה + קבלה חתומה

## מסילות (lanes/)

| מסילה | מה היא מודדת | תדירות-מוצעת |
|---|---|---|
| `sovereign-probe` | בדיקת-חיים של המכשיר + נגישות-הזנות | כל 15 דק' |
| `fresh-oracle` | גיל 9 הזנות מול מכסות → fresh-oracle.jsonl | כל 30 דק' |
| `integrity-verify` | STASIS + ריצות אחרונות + verdict כנה | כל 2 שע' |

כל מסילה: מדידה בלבד → קבלת-ריצה (SHA-256 + גוף) → push לתיקיית `results/` בריפו-הזה. **אפס כתיבה לריפואים של-בעלי-מסילות-אחרים** (חוק-גבולות-בעלות).

## השרשרת (anchor/)

כל קבלת-ריצה מקבלת `sha256` וגוף-מוכן-לפרסום (`payload.json`). הפרסום-בפועל לשרשרת (STEEM/HIVE) מתבצע רק על-ידי הכספת של הבעלים על-המכשיר שלו — הקיט לעולם לא מחזיק מפתחות-חתימה (דיגסטים-בלבד, חוק-אפס-חשיפה).

## אפס-תלות בדקות-GitHub — שתי-דרכים פתוחות

1. **Forge על-המכשיר (ראשית):** כל-הביצוע מקומי. GitHub מקבל רק פנקסים. אין דקות, אין תלות, אין סיכון-השבתה שמעצור-אותנו.
2. **Self-hosted runner (רשות):** `bash register-gh-runner.sh` — המכשיר נרשם כ-runner אמיתי של GitHub Actions. ריצות על החומרה שלנו = **חינם** (מקור-רשמי: docs.github.com — "Are free to use with GitHub Actions"). הריפו-הפרטי (Sandbox) חוזר לרוץ ללא-מכסה.

## תאימות-GitHub (למה הם לא יעיפו אותנו)

ראה `ToS-COMPLIANCE.md` — עם-ציטוטים-מדויקים מהמקורות-הרשמיים ומה-נבדק. קצר: אוטומציה-מתונה על-הריפואים-שלנו = שימוש-מיועד; כרייה/ספאם/עומס-מופרז = הדברים-היחידים-שאסורים, ואנחנו לא עושים אף-אחד-מהם.
